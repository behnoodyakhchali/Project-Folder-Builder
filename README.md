# Project Folder Builder

Create reusable project folder structures using customizable profiles.

Project Folder Builder is a lightweight macOS command-line tool that helps you create organized folder structures instantly from predefined profiles.

---

## Features

- Create project folders from profiles
- Unlimited custom profiles
- Simple command-line interface
- Modular Bash architecture
- Fast and lightweight
- Designed for macOS

---

## How It Works

A profile contains the folder structure you want to create.

Example:
1-Media
2-Sibelius Prj
3-Export
4-AI - Material
5-Material
6-Video
7-Recorded


Project Folder Builder creates:

Media
Sibelius Prj
Export
AI - Material
Material
Video
Recorded
